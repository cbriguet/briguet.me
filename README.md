# briguet.me

Christophe Briguet's one-page site. Static files only: `index.html` (inline CSS, no JavaScript, no external fonts, no analytics), `404.html`, `favicon.svg`, `og.png` (the link-preview card), `robots.txt`, `sitemap.xml` and `CNAME` for GitHub Pages.

Preview locally with `python3 -m http.server 8790` from this folder and open http://localhost:8790/.

The 2022 HTML5 UP "Dimension" template it replaces is in the history at commit bf64331.
